适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.7.0-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

### 新增：外观预设

设置里 `5. 界面 → 套用预设`，一键换一整套外观，选中后立即生效，然后自动回到 `None`：

- `Default` 战地 6 默认（把预设涉及的设置全部复位成默认值）
- `Legacy` 经典（0.3 的尺寸与配色）
- `Minimal` 极简（只留命中标记、伤害数字、骷髅 + 得分 + 名字）
- `HighContrast` 高对比 / 色盲友好
- `Tactical` `Operator` `Bloodbath` `Headhunter` `Slick` `NightOps` `Inferno` `Plague`：旧版 SimpleHitMarker 的 8 套配色

**套用前会自动备份** cfg（`com.aya.ayahitmarker.cfg.bak-preset-时间戳`，保留最近 5 份）。
套用的语义是：先把「任一预设涉及的设置」全部复位到默认，再写入所选预设的值，所以切换预设不会留下上一套的残留；
**这些设置里你手动调过的值会被覆盖**。位置偏移、音效、快捷键、计分规则、调试项、字体和语言永远不受影响。
击杀卡片与受击方向从下一次击杀 / 受击起生效。

### 新增：高对比 / 色盲友好配色

`HighContrast` 预设用 Okabe–Ito 色板，并在红 / 绿 / 蓝色盲的色觉模拟下逐组校验过「普通 / 爆头 / 击杀」是否分得开
（0.6.1 默认的爆头标记与击杀标记几乎同色）；同时加大爆头 / 击杀标记、加粗描边与环形，让区分不只靠颜色。
为此，原来写死在代码里的 7 个卡片颜色（骷髅普通 / 爆头、横幅底色、四种标签色）变成了配置项（面板 `32 击杀卡片 · 配色`，高级项），**默认外观完全不变**
（用 0.6.1 做了逐像素比对）。

### 新增：英文界面

`5. 界面 → 语言`：**自动**（默认，跟随游戏语言）/ 中文 / English。屏幕上的成就横幅、标签、击杀部位与方式、助攻提示、战局小结，
以及**设置面板的名称、说明和分类**都会切换。cfg 文件里的键名不变。设置面板的文字在**重新打开面板**后切换。

### 新增：战局小结

战局结束、回到主菜单后，屏幕上显示几秒本局统计：击杀 / 爆头击杀 / 最远一杀 / 最高连杀 / 得分 / 造成伤害 / 助攻 / 承受伤害 / 阵亡 / 获得的成就。
它在**主菜单可以操作之后**才出现（战局刚结束时游戏还在过场和结算界面）；什么都没发生的局（比如进出藏身处）不显示。
新分类 `12 战局小结`（cfg 分组 `6. 战局小结`）里可以调开关、停留时长、显示延迟、位置和字号。

### 新增：昵称音译（默认关）

`3. 击杀信息 → 昵称音译`：把击杀卡片和助攻卡片上的西里尔字母昵称（俄语 bot 名字）转成拉丁字母显示。只影响显示，不影响复仇判定。

### 修复：命中提示的爆头判定

0.6.1 及以前，**子弹命中的爆头判定其实从来没有生效**：命中标记的爆头配色 / 尺寸、伤害数字的爆头颜色、爆头命中音效都只在击杀的那一下
（击杀事件的部位是对的）或铁丝网这类环境伤害里才可能触发。现在改读被打中的碰撞体的部位，普通命中里打中头部也会显示爆头反馈。
一发打穿头盔的子弹（「板阶段 + 身体」两个事件）合并后也会保留爆头标志。

> 已在真实战局验证：一局 98 条命中全部读到了被打中的部位，6 条头部命中都判出了爆头，其余没有误判。
> 游戏把**颈部算作胸部**，这里与游戏保持一致（打脖子不算爆头）。
> 如果你打开了诊断日志，`[hit]` 行里的 `headSrc=` / `part=` 字段会显示读到了什么；本机子弹命中累计 30 次仍读不到部位时日志会告警一次，
> 遇到请把日志发给作者。

### 升级说明

- 配置版本不变（仍为 3），**无需删除 cfg**；新增 16 个设置项（`语言`、`套用预设`、`昵称音译`、7 个卡片颜色、6 个战局小结设置），没有改动任何已有设置的默认值。
- 游戏启动的头一秒内，自动语言读到的游戏语言会先是 `en` 再变成实际语言，这时屏幕上还没有任何文字，不受影响。

**验证**：1185 项离线测试通过；DebugHarness 在主菜单实机验收——英文屏幕文字 11 张、战局小结 12 张（含「战局结束 → 等菜单 → 延迟 → 显示」的完整调度路径）、
预设 19 张（跑完还原后 cfg 与备份字节级一致）、连杀缎带 5 张、卡片 16 张与 0.6.1 逐像素一致。
**真实战局验证（2026-10-26）**：命中级爆头（98 条命中全部读到部位、6 条头部命中判出爆头）；战局小结（主菜单场景在战局中会被卸载，战局结束 17 秒后菜单出现、再 3 秒显示）；设置面板切换语言与英文游戏下的字形目检正常。

升级保留已有 cfg，无需删除配置。卸载只需删除 BepInEx/plugins/AyaHitmarker。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

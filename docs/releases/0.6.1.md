适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.6.1-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

### 修复：护甲命中标记几乎看不到

0.6.0 把「没有身体伤害、只有护甲伤害」当作护甲命中，实机日志证明这个判据基本不会可见地触发：

- 一发**击穿**护甲的子弹会产生两个命中事件：先是「打在护甲板上」（只有护甲耐久伤害），紧接着同一帧再来一个落在身体上的事件。
  旧版把前一个当护甲命中，却被后一个当帧覆盖，蓝色标记根本看不见。
- 真正**被挡下**的子弹只有一个事件，且带少量钝伤（身体伤害 > 0），反而被旧判据漏掉。
- 副作用：一发穿甲子弹会触发两次命中标记 / 命中音效 / 伤害数字；助攻伤害把护甲耐久也算了进去（一发约 100）。

现在把同一发子弹的两个事件合并成一次命中，并区分两种结局：

- **被挡下**（包括钝伤为 0 的）：命中十字加蓝色辉光；受击方向点阵仍用白色。
- **击穿护甲**：命中标记保持普通，不带辉光。

### 改进：护甲伤害数字另起一行

带护甲耐久伤害的命中，**护甲数字（蓝色 + 小盾标）显示在身体伤害数字的上方**，两种排布（一行向右 / 累加）都适用：
累加样式里一个目标的槽最多两行，护甲伤害单独累计。被挡下且钝伤为 0 时只有护甲数字。
`2. 伤害数字 → 取值 = Total` 仍是旧行为（一个数字 = 身体 + 护甲）。`1. 命中提示 → 护甲命中标记` 关闭时，辉光和护甲数字一起不显示。

### 其他

- 助攻累计的伤害只算身体伤害，不再把护甲耐久算进去。
- 诊断日志的 `[hit]` 行补充了 `raw` / `penetrated` / `blunt` / `blockedBy` / `deflectedBy` 等原始字段，并新增 `[hit] 护甲判定` 行，方便以后对照。
- 测试快捷键 `F8`（随机命中）现在会随机出挡下 / 零钝伤挡下 / 击穿三种护甲命中。

- 配置版本不变（仍为 3），**无需删除 cfg**；没有新增设置项。

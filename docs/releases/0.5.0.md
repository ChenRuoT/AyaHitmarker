适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.5.0-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

- 命中提示、伤害数字、战地风格累加击杀卡片、多杀与成就横幅。
- 附带四种音效、基础 PNG 图标和 16 个军衔图标，解压即可使用。
- 设置面板分类、高级项显隐、颜色与偏移编辑；军衔徽记与骷髅图形调整。
- 统一插件与程序集版本，建立自动测试、构建、tag 和 Release 发布流程。

升级保留已有 cfg，仍为旧默认值的样式会自动迁移。卸载只需删除 BepInEx/plugins/AyaHitmarker。

离线逻辑与 CI 构建验证不能代替实际游戏中的动画、声音与设置面板验收。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.5.3-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

- **修复连续战局命中反馈消失**：同一游戏进程里第 2 局起，命中标记和命中音效会整局不出现（击杀反馈正常）。
  原因是 `GlobalEventDispatcher` 的实例在 EFT 1.2.0.0 里跨局不变，而游戏换局时会清掉 `OnBeingHit` 的订阅；
  旧版只在启动时订阅一次，所以从第 2 局起就再也收不到命中事件。现在**每局开局都会重新绑定**（幂等），
  三连局实测 99 条命中事件全部收到。
- **战局边界改用「主玩家」判定**：进图 = `GameWorld.MainPlayer` + 档案出现，回菜单/结算 = 消失。
  连带修正：连杀 / 每局击杀数 / 得分 / 成就跨局累计，以及开局不清空 UI、不重载音效的问题。
- 新增诊断日志（始终输出，便于反馈）：`[events] raid started (main player)`、
  `[events] OnBeingHit 已绑定（raid started…）`、`[events] 本局第一发 OnBeingHit`，
  以及 `[diag]` 里的 `raidState=`。
- 配置版本不变（仍为 3），无需删除 cfg。

**验证**：315 项离线测试通过；同一进程三连局实测（S2 挨打事件 5 条、第 2 局 99 条命中事件）、
逐局重绑成功、无插件告警；此前复现的「第 2/3 局 0 条命中事件」不再出现。

升级保留已有 cfg，无需删除配置。卸载只需删除 BepInEx/plugins/AyaHitmarker。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

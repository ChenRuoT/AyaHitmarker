适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.5.1-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

- 修复战局中音效丢失：音效对象仍显示 Loaded，但采样数据已被清空时，现在会识别失效并异步重载。
- 加强音效资源保活，回收重载时替换的旧请求和音频资源。
- 保留异步加载与加载中断清理，播放路径不执行文件读取或同步加载。
- 附带四种音效、基础图标和 16 个军衔图标。

**验证**：315 项离线测试通过；游戏脚本成功复现零采样故障并自动恢复，四类音效两轮共 8 次播放均正常进入播放状态。用户真实战局实测确认音效丢失已修复。

升级保留已有 cfg，无需删除配置。卸载只需删除 BepInEx/plugins/AyaHitmarker。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

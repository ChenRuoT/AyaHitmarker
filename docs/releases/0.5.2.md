适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.5.2-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

- 音效空间模式默认由 `Flat2D` 改为 `FollowCamera3D`（唯一在真实战局里确认过出声的模式）。配置版本 2 → 3：
  升级时只把仍等于旧默认 `Flat2D` 的值换成新默认，手动调过的保持原样，无需删除 cfg。
- 修复设置面板分类顺序：`00. 常用与整体界面` 原来排在最后、`90. 调试与排障` 排在最前，现在按设计顺序排列。
- 字体：停止探测在当前离线版本上注定失败的系统字体；中文由游戏自带字体的回退链覆盖（屏上 114 个字符缺字形 0 个），
  启动日志会写一行字形覆盖情况。FAQ 里「字体填 Microsoft YaHei」的误导建议已更正。
- 完善卸载路径：新增对画布 / 音频宿主 / 图标与字体缓存 / TMP 材质实例的显式清理，热重载逐代泄漏实测为 0。
- 卸载清理的每一步彼此独立：画布、音频宿主、图标、字体任一环节失败都不会拖累其余清理。
- 开发工具：支持 ScriptEngine.IL2CPP 热重载迭代（`-p:HotReload=true`）、遥控模式与逐帧截图验证，新增 Issue 反馈模板。

**验证**：315 项离线测试通过；`dotnet build` 0 warning / 0 error；设置面板在游戏内逐项验收（枚举 / 颜色 / 偏移 / 滑块 / 快捷键 / Reset / 持久化）；
连续 14 代热重载 0 error，多代后截图与第 1 代逐字节相同，Texture2D / Sprite / TMP 字体 / Font / Material 逐代增量为 0。

升级保留已有 cfg，无需删除配置。卸载只需删除 BepInEx/plugins/AyaHitmarker。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

适用 **SPTushonka 5.x / EFT 1.2.0.0（build 47965），IL2CPP，BepInEx 6 CoreCLR 10**。

下载 **AyaHitmarker-v0.6.0-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖文件。
不要下载 GitHub 自动提供的 Source code；其中没有已编译插件。

### 新功能

- **受击方向指示**（默认开启，可关）：自己被打时，屏幕中央一圈看不见的椭圆上，在攻击者所在的方位亮起一簇**规则排列的点阵**，
  收尖的峰尖精确指向攻击者；伤害越高越大。颜色分三档：只被护甲吸收 = 白色、普通伤害 = 黄色、重伤（默认 ≥ 35）= 红色。
  外观**全部可调**：设置面板里单独的分类「**11. 受击方向**」（不透明度、点大小 / 间距、突起宽度与高度、同时最多簇数、时长、渐变、颜色等），
  改完下一簇就生效。觉得挡视野，先调「整体不透明度」或「同时最多簇数」。
- **护甲命中区分**：只打中防弹板（没有肉体伤害）时，命中十字外加一圈**蓝色辉光**，伤害数字右侧显示一个**小盾标**；可关闭。
- **累加伤害数字**（可选，`2. 伤害数字 → 排布方式 = 累加`）：战地 6 样式，同一目标的伤害在同一位置滚动累计，击杀时变红；
  默认仍是原来的「一行向右」。
- **助攻提示**：你打过的目标在 8 秒内（可调）被别人打死时，在击杀卡片下方弹出一条「助攻 +伤害」的简化卡片；可关闭。
- **连杀音效**（可选）：在 `Sounds/` 里放 `double_kill` / `triple_kill` / `multi_kill`（ogg / wav / mp3），双杀 / 三杀 / 多杀时播放；
  没放就仍用普通击杀音效。

### 测试快捷键

- `F8` 改为**随机命中**（伤害 / 是否打中护甲 / 是否爆头随机）。
- 新增 `P`：**随机受击**（方位 / 伤害 / 是否只被护甲吸收随机），用来边调「11. 受击方向」边看效果。
  测试快捷键都可以在「90. 调试与排障」里改键或关闭。

### 修复

- 设置面板里改双杀 / 三杀 / 多杀音效路径后，要等下一局才生效。
- 0.6 开发期间加载阶段曾因漏了配置面板映射而整个插件加载失败，已修复并加了离线检查。

### 升级说明

- 配置版本不变（仍为 3），**无需删除 cfg**；新设置项会自动以出厂值写入。
- 设置面板新增分类「11. 受击方向」，排在「10. 命中提示」之后。

**验证**：616 项离线测试通过；DebugHarness 实机截图验收（护甲样式、累加数字、助攻卡、受击方向点阵在暗底 / 白底 / 雪地、持续挨打）；
两局真实战局复查：每局都重新绑定命中事件，受击 7 / 1 次各出 7 / 1 簇指示，第 2 局命中反馈正常。

升级保留已有 cfg，无需删除配置。卸载只需删除 BepInEx/plugins/AyaHitmarker。
旧 SPT 4.x / Mono 请使用 [SimpleHitMarker](https://github.com/ChenRuoT/SimpleHitMarker)。

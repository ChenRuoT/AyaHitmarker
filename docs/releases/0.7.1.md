# 0.7.1 — 击杀经验与日志可观测性

适用 SPTushonka / EFT 1.2.0.0 build 47965，IL2CPP，BepInEx 6 CoreCLR 10。

下载 **AyaHitmarker-v0.7.1-EFT-1.2.0.0.zip**，关闭游戏，将其中的 **BepInEx** 文件夹解压到 **EscapeFromTarkov.exe 所在目录**，允许覆盖。
保留已有 cfg，无需删除配置；GitHub 的 Source code 不包含已编译插件。

- 击杀卡片与战局小结改为按游戏规则计算的击杀经验；从实际后端读取规则，冻结受害者模板输入，独立计算爆头与本局累计击杀 combo 奖励。整局倍率固定 ×1，不含伤害、拾取、治疗等经验。
- 缺少输入时隐藏卡片经验，小结显示“不可用”，日志记录原因，避免把部分累计当完整总数。同组击杀不授予经验。
- 移除 6 个自编计分配置及相应孤儿键。保留已有外观设置的 cfg 键名与值，面板显示名称改为“经验 / XP”。未改变默认值，配置版本仍为 3，无需删除 cfg。
- 所有插件日志行尾附加相对加载时间 `@t=…`，事件线程也可使用。
- 每局记录被跳过的音效请求、clip 失效到恢复的耗时、局末未恢复数，并区分音效关闭、音量为 0 和 clip 缺失。可选连杀音效成功回退时不算静音。
- 中英文辉光说明明确仅适用于 `CustomFiles`；修正旧的“自己受击不显示提示”文档。
